CHART · cumulative.json ← witness_blocks.csv + blocks.csv

The pile: cumulative non-monetary bytes

Estimated running total of non-monetary bytes: inscription payloads in witness space, with OP_RETURN data stacked on top. Signatures, control blocks and ordinary spending scripts are excluded — only bytes that serve no monetary function are counted.

What counts: envelopes are OP_FALSE OP_IF … OP_ENDIF — a branch the script interpreter never executes, so it can carry data and nothing else. Every envelope byte is non-monetary by construction, whichever protocol wrote it. Signatures, taproot control blocks and ordinary spending scripts are counted as overhead and excluded here. Honest print: totals are extrapolated from sampled blocks (sum × step) and marked estimated. Coverage windows differ — OP_RETURN has existed since 2014 but is measured here only from the start of its dataset, so its early total is understated. On permanence: every node downloads these bytes; archival nodes store them forever; pruned nodes may discard block and witness data after validation. The strictly unprunable UTXO set is not measured here.
